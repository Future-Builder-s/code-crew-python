## 🚀 How to Contribute Code
1. **Fork** this repository to your own GitHub account.
2. **Clone** your fork to your local machine.
3. Create a branch named after you (`git checkout -b feature/your-name`).
4. Commit your daily practice files (`git commit -m "Added my practice code"`).
5. Push your branch (`git push origin feature/your-name`).
6. Open a **Pull Request** to merge it into the main team project.
